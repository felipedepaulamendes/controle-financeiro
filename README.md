Um organizador financeiro pessoal feito com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar entradas e saídas
- Calcular saldo, total de entradas e de saídas
- Excluir movimentações ou limpar a lista inteira
- Salvar os dados no navegador com `localStorage`
- Layout responsivo para celular e computador

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Adicione suas movimentações.

## Tecnologias

- HTML5
- CSS3
- JavaScript
